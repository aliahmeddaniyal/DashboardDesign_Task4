# Task 4 - Dashboard Design

## Objective
The objective of this task was to design an interactive business dashboard using Power BI. The dashboard helps stakeholders analyze sales performance, profit trends, product performance, and regional sales distribution.

## Tool Used
- Power BI Desktop
- GitHub

## Dataset
Superstore Sales Dataset

## KPIs Used
- Total Sales
- Total Profit
- Total Quantity Sold

## Dashboard Features
- Sales Trend Analysis (Line Chart)
- Profit by Category (Bar Chart)
- Sales by Region (Pie Chart)
- Top Products by Sales (Column Chart)
- Interactive Filters (Date, Region, Category)
- KPI Summary Cards

## Insights
- Sales showed consistent growth from 2015 to 2017.
- Technology category generated the highest profit.
- The West region contributed the highest sales.
- A small number of products generated a large portion of total sales.

This project helped in understanding dashboard design, KPI visualization, data analysis, and creating interactive reports for business decision-making.
